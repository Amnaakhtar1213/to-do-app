##  TODO-APP

A Simple, clean and interactive todo list application built with *HTML*, *CSS* and *JAVASCRIPT*.It help you to add, manage and filter tasks while keeping the track of what's left.

--------------------------------

##   FEATURES

- Add tasks quickly by clicking add button or Enter button.
- Mark tasks as completed with checkbox.
- Delete tasks with a single click.
- Filter tasks by:
  
     - ALL
     - Active
     - Completed

- Clear completed task in one go.
- Store data using localStorage so your task stay even after refresh.
- Item left counter to keep record of pending tasks.
- Empty state message when no task match the filter.
- Display today's date also.

-------------------------------

##  TECHNOLOGY

1. **HTML**
2. **CSS**
3. **JAVASCRIPT**
4. *localStorage* (for storing data)
